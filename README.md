# datasqrl.github.io

The DataSQRL documentation has moved to **https://docs.datasqrl.com**.

This repository serves only a redirect via GitHub Pages. `index.html` and `404.html` are identical, so the root URL and any old deep link (e.g. `datasqrl.github.io/docs/...`) forward to docs.datasqrl.com with the path, query string, and anchor intact.
